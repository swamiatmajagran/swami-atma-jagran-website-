SWAMI ATMA JAGRAN — PRODUCTION DEPLOYMENT

This package preserves the existing website design and adds only the requested payment/data workflow changes.

Vercel Production Environment Variables required:
- RAZORPAY_KEY_ID
- RAZORPAY_KEY_SECRET
- RAZORPAY_WEBHOOK_SECRET
- OWNER_NOTIFICATION_EMAIL
- JIGYASU_ADMIN_PASSWORD
- RESEND_API_KEY (provided by the Vercel/Resend integration)
- RESEND_EMAIL_DOMAIN (provided by the Vercel/Resend integration)

Razorpay webhook:
https://swamiatmajagran.in/api/payment-webhook

Recommended webhook event:
- order.paid

Payment flow:
Buy Now -> customer details + email -> PAY NOW -> Razorpay Standard Checkout -> server verification -> Congratulations screen.

Customer email and owner notification are sent by the Razorpay order.paid webhook through Resend.

The public Jigyasu Patal shows only Name, Product, 24-hour delivery countdown and payment status.
Sensitive DOB, gender, birth time, birth place, WhatsApp and email are available only through the password-protected Your Chart Data panel.

No Cloudflare Worker is required.
